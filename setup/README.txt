Pure Guard setup (PC)

Copy this whole folder to the laptop (or run it from a USB stick). Nothing to install.

1. On the phone: Settings > About phone > tap "Build number" 7 times.
2. Settings > Developer options: turn on USB debugging.
   Xiaomi / Redmi / POCO: also turn on "Install via USB" and "USB debugging (Security settings)".
3. Double-click setup.bat, plug the phone in, tap "Allow" on the phone.
4. On the phone (Xiaomi): Pure Guard asks for two steps first: battery saver
   "No restrictions" and Autostart on.
5. Create the unlock password. The accountability partner keeps it.

Pure Guard does not stop anyone from uninstalling it. If it gets uninstalled,
install it and run setup again.

If the phone is not found: try another cable or USB port. Some Samsung phones need
Samsung's USB driver on the laptop (search "Samsung Android USB Driver").

Without a PC:
- Android 11+: open Pure Guard > "Wireless debugging". Follow the steps; the 6-digit
  pairing code is typed into Pure Guard's notification. (Shizuku also still works.)
- From another phone that has Pure Guard: "Activate another phone" > "By cable (USB OTG)"
  (any Android 8+ phone, USB debugging on) or "By Wi-Fi" (same Wi-Fi, Android 11+,
  type the code from the other phone's "Pair device with pairing code" popup).
  Pure Guard is installed on the other phone, then set up. Finish there with the password.
